## Quick start

### Using it

Grab the latest release for your OS from the [releases page](https://github.com/OWNER/REPO/releases/latest):

- **Windows**: `APP-Setup-x64.exe` (or `winget install APP`)
- **macOS**: `APP.dmg` (or `brew install --cask app`)
- **Linux**: Flatpak, `.deb` or `.AppImage`

### Running it yourself

```bash
docker run -d --name app -p 8080:8080 ghcr.io/owner/app
```

Build from source and full configuration: see the [documentation](https://example.com/docs).
