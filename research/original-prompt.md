Good Github Readme Skill
The purpose of this skill is to give non-technical and technical users a good understanding of the application without being overly verbose. Currently any readme's generated by AI (such as you claude, openai, etc.) contain too much technical information and making it overly verbose.
Thing's I have noticed that make the repo look nice
Some type of title image or bar
Badges to show proofs such as tests, social media links, npm/pyton versions, ect.
GitHub Star History at the bottom to get a sense of popularity over time
Organized screenshots of the application in use to actually see the GUI and the usage.
Good and simple setup instructions
I have pulled some specific examples from my github stars. Research them in detail and see what they have in common on the non-technical user and technical user aspect.
